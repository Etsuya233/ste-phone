# 人物资料覆写按聊天保存

状态：接受。2026-11-12。

同一个稳定人物可以出现在多个 ST 聊天和多个 Memory 实例。Phone 在聊天元数据中按稳定资料空间和人物保存字段覆写，使同一聊天重新加载资料实例时能继续使用覆写，聊天分支也能随元数据继承当时的设置。若仅以稳定资料身份全局保存，修改就会传播到共享该人物的其他聊天。

资料应用合并来源和覆写，为手机业务提供有效人物资料；Memory 执行的标准视图继续返回已提交的来源数据。这样既能统一资料展示和 AI 取材，也能保留可独立核对的来源查询，代价是人物业务调用方需要统一迁移到资料应用的人物读取接口。该方案沿用 [ADR 0002](0002-memory-executes-phone-views.md) 的查询边界和 [ADR 0008](0008-stable-memory-identity.md) 的身份约定。
