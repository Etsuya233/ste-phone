# Phone 拥有可重建的只读资料投影

状态：历史决策，已由 [0002](0002-memory-executes-phone-views.md) 取代。

Memory 的公开契约提供已提交快照和变更通知，尚未提供 SQL 与 semantic 查询。Phone 通过该契约将完整公开源结构导入自己的内存 SQLite，并拥有版本化的 `phone_*` 标准查询契约；Memory 适配器负责原始字段与标准视图的对应，`src_*` 保留源业务结构，以支持自定义查询并隔离来源变化。

每次导入先完成候选库的全量构建和校验，再原子替换旧库；失败保留同范围旧投影并显示过期。这样查询始终面对一份完整快照，代价是刷新时短暂同时占用新旧数据库内存，并且来源提交到本地投影更新存在弱一致性时间差。聊天与范围共同决定归属，旧代次异步结果不能发布到当前会话。

资料投影随页面刷新重建，当前编辑会话也仅保留在内存。Phone 后续的联系人、消息和日记等业务数据应独立拥有并按聊天保存，避免把可丢弃投影和用户业务数据混合；本轮不实现这些业务、设置或 semantic 接口，也不依赖 Memory 内部 runtime、数据库或相邻源码。
