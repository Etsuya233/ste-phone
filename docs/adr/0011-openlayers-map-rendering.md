# 地图使用 OpenLayers 管理绘制与标签避让

状态：接受，2026-11-06，用户在独立对照后确认完整接入。

地图的绘制和指针交互改用 OpenLayers Canvas VectorLayer，标签碰撞交给 Text declutter。独立对照中用户更认可它的交互和显示效果，桌面测试也显示减少主线程绘制开销。此选择不承诺降低 iPhone WebContent 进程总内存或消除 Jetsam；手机键盘、宿主布局和长期保活仍须真机验证。

地图仍保存原有平面坐标与稳定要素 ID，MapService 继续拥有文档、查询高亮和提案。渲染层只将状态转换成图形、回传选中的 ID 或整数平面坐标，不生成业务位置，不调用模型或自行保存地图。AI 工具、应用与撤销协议保持不变。

每个挂载的地图工作区持有一个 OpenLayers Map。文档、选择和查询分别更新图层与视图，Home 和关闭手机保留视角，聊天或稳定空间变化及退出应用销毁实例。尺寸变化合并到动画帧并调用 updateSize。空图与位置待定要素均为合法状态。

应用负责语义样式、图层顺序、标签优先级与边缘展示、选中状态、提案旧轮廓和位移线；库负责视图变换、Canvas 绘制、碰撞避让和点击命中。装饰及提案旧图形不参与语义选择。保留 OpenLayers 的显示风格，无需逐像素复刻旧 Leaflet 纹理。

Leaflet 暂留为开发依赖，独立对照页可继续运行原先的基线。正式入口和样式不再加载 Leaflet，历史性能报告保留当时的实现边界与数据。
