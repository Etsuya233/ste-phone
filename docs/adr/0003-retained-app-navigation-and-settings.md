# 保留 App 会话、页内导航和全局壁纸设置

状态：接受。

手机现有 Home 和窗口关闭会卸载 App，资料详情替换列表会丢失搜索及滚动，无法表达后台切换。固定五个 App 使用首次启动挂载、Home 保留、Expose 明确退出卸载的生命周期，无 LRU。dialog 关闭保留整个 `PhoneDevice`，重开回到原前台页，刷新 ST 才结束内存会话。已存在的资料/数据库公共服务缓存独立于 App 页面，退出页面不清服务；数据库编辑工作区继续按聊天与资料范围保存。

Foundation 的 `NavigationStack` 保留普通 DOM 页面，隐藏下层并设为 inert。Push 和 Pop 使用水平滑动，Pop 完成后才卸载顶页，转场锁定导航并遵循减少动态效果，返回恢复触发元素焦点。Foundation 的三级样例、资料分类/列表/详情、数据库对象列表/详情与设置主页/壁纸使用同一能力。资料聊天或范围变化重建栈，不缓存跨聊天页面栈；DB 继续恢复自己的工作区。

App 的 `active` 明确控制焦点和显示计时。后台秒表依赖 `performance.now()` 正确累计时间，停用显示 RAF。隐藏 DB 页不监听/恢复滚动，恢复前台才从工作区恢复，防止 display:none 的尺寸变化覆盖原滚动值。物理/软件 Home 共用 280ms 单双击，Expose 同时提供主屏单击入口；预览不复制 App DOM。

Expose 最初采用摘要卡。用户要求 iOS 7 的横向页面预览后，改为保留 App 层自身并进行 CSS 缩放和位移，中央卡片露出两侧邻卡，下方复用主屏图标。真实 DOM 能直接保留当前页面内容和滚动，避免复制组件产生第二份状态，也不依赖截图服务。每个 App 的父节点、内容 wrapper 和 key 始终稳定；内容保持 inert，独立的透明手势/按钮层处理打开、横向选择与上滑退出。退出动画结束才从会话移除，关闭窗口收敛退出动画并清理拖动。当前卡采用 roving Tab，方向键、Enter、Delete 支持键盘操作；减少动态效果时直接完成。按用户参考图进一步移除额外页码、提示、主屏/退出按钮、后台外层状态栏和主屏后台入口，只保留壁纸、预览卡片与应用图标名称。最后一个应用退出后显示壁纸，仍可通过 Home 返回主屏。

全局设置通过注入的 `PhoneSettingsService` 连接存储。生产适配器使用 ST 公开上下文、`extensionSettings.ste_phone` 和 `saveSettingsDebounced()`。本决策最初的 ST 背景与外部 URL 壁纸方案由 [0004](0004-uploaded-wallpaper-library.md) 的上传图库、v2 设置和独立预览 Blob 存储取代。壁纸独立层使用 Blur，手机内容保持清晰，不修改宿主背景。
