# Phone 独立模型连接与 Pi 运行边界

状态：接受，2026-10-31 主代理与用户指定的 Sol Medium 子代理逐轮问答收敛，用户审阅并确认；模型连接与文本测试已实现。

Phone 独立拥有跨聊天的命名模型连接与默认连接，使用 Pi Agent 作为 AI 运行基础。借鉴 Memory 的应用层组装与 ST 同源代理适配边界，首期由连接测试流程直接创建 Pi Agent；ST 适配器通过 Custom 源转发 OpenAI Chat Completions 并转换流事件。当前没有业务 AI 功能，共享运行能力等具体 App 出现生成需求后再确定。连接配置不依赖 Memory 的私有实现或设置，也不修改 ST 主连接及密钥。该选择复用宿主代理，避免浏览器直连要求上游开放 CORS。

自定义请求头只进入上游代理参数，宿主请求继续使用宿主的请求头。每次显式提供 Authorization，包括空鉴权，隔离宿主 Custom 源密钥。连接密钥及请求头值随 Phone 设置明文保存，界面说明这一点。ST 代理属于内部接口，将契约集中在基础设施层并通过宿主验收覆盖。

设置沿用 ST 的延迟保存；单次调用取得连接配置副本，运行期间的修改影响下一次调用。删除默认连接清空选择，缺少默认连接时明确报错。无需引入跨标签协调、修订仲裁、事务或持久任务。Memory 的提案提交、任务队列和业务工具不属于首期范围。

详细方案与逐轮问答见 [基础 AI 与模型连接方案](../../.scratch/model-connections/spec.md)。
