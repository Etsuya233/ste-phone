# ADR 0016 微信群聊共享会话

微信群聊使用独立 ID，单聊继续使用稳定资料空间与两个人物共同确定的 ID。微信 v6 为旧单聊补充会话类型。群保存当前成员 ID 和曾经参与的人物身份，前者用于判断帐号访问权和本轮发言资格，后者用于保留历史消息的署名。群资料和成员增删记录一次写入，所有群成员共用消息、记忆屏障和发送记录。移出成员以及变成单人群时关闭不再适用的待回复队列，保留全部历史。

群聊与单聊复用发送、生成和保存锁。每轮群聊请求固定发起帐号和可发言成员，使用一次模型调用返回按发言顺序排列的消息。结果包含无权发言的人物、漏掉指定发言者，或使用不支持的消息类型时，整批拒绝。提示词只使用本群获准的微信历史，仍取当前群成员的完整资料及相关剧情背景。生成中的成员写入会被拒绝，已发出的保存请求沿用原 ST 聊天归属。
