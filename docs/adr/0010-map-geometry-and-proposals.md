# 地图保存实际几何与显式提案

状态：接受，2026-11-05，基于用户确认的地图 Agent 设计。

地图应用保存模型产生并经代码整批校验的平面坐标、粗略多边形与道路控制点，Leaflet 只负责绘制和交互。持久几何作为后续修改的权威输入，局部操作保留无关要素；不引入覆盖多种世界的模板布局引擎，避免继续编辑时重排用户已经确认的位置。模型返回严格分型的查询或增量提案，查询只临时高亮已有要素，路线由既有道路连接校验，显式应用才保存。

数据按 ST 聊天和来源稳定空间隔离，即使两个聊天拥有同一稳定空间身份也分别维护。继续调整以候选图为输入，版本检查仍针对原保存版本；撤销保存先前几何并推进版本。生成取消丢弃迟到回复；已向 ST 提交的保存固定原聊天、等待完成，不进行全聊天回滚。来源资料始终只读，地图补充内容标注来源及推测，历史地图的浏览不要求模型和 Memory 在线。
