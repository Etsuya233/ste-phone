# 前端开发与验收

运行 `pnpm preview:frontend`，打开 `http://127.0.0.1:18826/`，点击右下角“手机”按钮。服务默认监听 `0.0.0.0`，同一局域网设备使用终端输出的本机 IPv4 地址访问；`HOST` 和 `PORT` 可指定监听地址、端口。桌面与移动端默认显示完整 iPhone 6s 机身，按可用视口等比缩放，不裁掉上下边框或 Home 键。关闭控件位于机身之外。关闭按钮与 Escape 均应关闭窗口；关闭后可重新打开，焦点回到入口。修改代码后刷新页面。

预览使用 esbuild 的监听与静态服务，产物放在 `node_modules/.cache/frontend-preview/`，不连接 ST、不读 API 配置、不写入真实对话。

可选能力的验收入口为 `/?draggable=1` 和 `/?responsive=1`，也可组合为 `/?responsive=1&draggable=1`。默认地址不启用这些能力。拖拽从机身顶部发起，移动不能使关闭入口离开视口；缩小窗口后仍需可达，关闭重开恢复居中。可选全屏模式只在窄屏启用，并保留软件 Home。

机身外观参考 [Apple 官方 iPhone 6s 图片](https://cdsassets.apple.com/live/7WUAS350/images/iphone/iphone-6s-colors.jpg)，按 430×886 逻辑机身、375×667 内屏重建深空灰正面，参考图不作为运行时资源加载。

执行 `pnpm typecheck`、`pnpm lint`、`pnpm format:check`、`pnpm test` 和 `pnpm build` 验证工程。`pnpm test` 使用隔离临时仓库检查 Junction 的创建、解除和错误目标保护，以及同步和离线发布。

真实 ST 接入：配置 `.env` 后运行 `pnpm build`、`pnpm st:link`，刷新 ST 页面，验证入口、窗口开关、样式隔离与窄屏布局。开发监听用 `pnpm watch`。解除直连用 `pnpm st:unlink`。具体命令与发版流程以 README 为准。

独立预览使用隔离的测试数据，避免向用户真实对话写入。独立预览通过后，ST 入口、宿主样式、聊天切换和持久化仍需在专用测试对话中验证。

验收报告注明实际执行的检查、结果与未验证范围。截图、日志和本地报告放在忽略目录；已跟踪文件不得引用 tmp 中的资源。

## 工程接入验证（2026-10-30）

类型检查、Lint、格式检查、生产构建及 5 项工程测试通过；watch 首次构建、manifest 修改重建与 Junction 跳过拷贝通过。本仓库发布 dry-run 通过，真实发布提交在隔离临时仓库验证，没有推送远端。

Edge 无头浏览器验证了桌面窗口尺寸、打开关闭、Escape、焦点恢复、320px 与 390px 窄屏，以及 Shadow DOM 和全局加载 CSS 的双向隔离。真实 ST `http://127.0.0.1:8000/` 自动发现并加载插件，入口与窗口开关通过；未执行聊天或模型请求。

## 手机页面约定

`device/` 管理当前页面与进入、退出转场，主屏常驻，秒表在退出动画完成后卸载；关闭原生 dialog 会卸载整个手机会话。秒表使用 `performance.now()` 与累计时间计时，刷新仅更新显示，退出或关闭后重进从零开始。

`foundation/Page` 提供唯一内容滚动层，顶部预留状态栏与可选导航栏，底部预留可选 footer 与安全区，scroll-padding 与内容内边距同步。导航和 footer 半透明叠在内容上；系统状态栏独立于应用转场。320px、390px、矮屏与放大文字时检查完整机身、首尾内容、关闭入口及 Home 均可达，应用缩放动画的起点需要从实际屏幕坐标换算到逻辑坐标。键盘进入应用后落在返回按钮，退出回秒表图标；动画期间阻止重复导航并支持减少动态效果。全屏响应式模式与拖拽只在代码中显式启用时生效，默认界面不提供切换控件。
