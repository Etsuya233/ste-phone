# 前端开发与验收

2026-10-30 发版验收：真实 ST 在 1280px、390px、320px 验证魔法棒菜单「小手机」入口可见可点，生产不再显示浮动入口；打开手机收起宿主菜单，X 与 Escape 关闭后焦点回到魔法棒按钮。桌面 Enter 操作通过，窄屏按触控设备配置验证，未修改用户聊天。

运行 `pnpm preview:frontend`，打开 `http://127.0.0.1:18826/`，点击右下角“手机”按钮。服务默认监听 `0.0.0.0`，同一局域网设备使用终端输出的本机 IPv4 地址访问；`HOST` 和 `PORT` 可指定监听地址、端口。桌面与移动端默认显示完整 iPhone 6s 机身，按可用视口等比缩放，不裁掉上下边框或 Home 键。关闭控件为摄像头右侧空闲区域的 X，不额外占用机身外空间；缩放后保持 44px 实际点击区域。关闭按钮与 Escape 均应关闭窗口；关闭后可重新打开，焦点回到入口。修改代码后刷新页面。

预览使用 esbuild 的监听与静态服务，产物放在 `node_modules/.cache/frontend-preview/`，不连接 ST、不读 API 配置、不写入真实对话。

可选能力的验收入口为 `/?draggable=1` 和 `/?responsive=1`，也可组合为 `/?responsive=1&draggable=1`。默认地址不启用这些能力。拖拽从机身顶部发起，移动不能使关闭入口离开视口；缩小窗口后仍需可达，关闭重开恢复居中。可选全屏模式只在窄屏启用，并保留软件 Home；关闭按钮位于底部 Home 操作区右侧，避免遮挡导航栏右操作。

基础组件从主屏的「组件」（Foundation）图标进入；独立预览也支持 `/?foundation=1` 快捷入口，可组合 `&responsive=1` 在窄屏按原始控件尺寸检查。覆盖应用的展开、返回与 Home 退出、焦点回到对应应用图标，以及开关的点击与空格切换、禁用态、分段控件的点击及方向键选择、按钮与列表操作、长标题和长单元格文本、可选顶栏与底栏、滚动后首尾内容可达。组件应用通过 Home 或关闭后保留状态与原页面；后台的「退出应用」清空该 App 页面。快捷入口仅决定首次打开页面。滚动到组件末尾进入导航详情，再进入下一层，逐级返回检查滚动、控件状态、焦点与左右滑动动画。

机身外观参考 [Apple 官方 iPhone 6s 图片](https://cdsassets.apple.com/live/7WUAS350/images/iphone/iphone-6s-colors.jpg)，按 430×886 逻辑机身、375×667 内屏重建深空灰正面，参考图不作为运行时资源加载。

依次执行 `pnpm typecheck`、`pnpm lint`、`pnpm format:check`、`pnpm test` 和 `pnpm build` 验证工程，避免同时运行多个 WASM 或构建任务。`pnpm test` 以 `--test-concurrency=1` 串行检查资料缓存、数据库映射、远端查询、标准视图 SQL 和聊天归属，并使用隔离临时仓库检查 Junction 的创建、解除和错误目标保护，以及同步和离线发布。

真实 ST 接入：配置 `.env` 后运行 `pnpm build`、`pnpm st:link`，刷新 ST 页面，从输入区魔法棒菜单打开「小手机」（`#ste-phone-wand-entry`，`aria-label="打开小手机"`）。生产界面只提供这个入口，右下角浮动按钮保留在独立预览。检查菜单项沿用 ST 的图标、文字及交互样式，点击后魔法棒菜单收起、手机打开；关闭按钮和 Escape 均应把焦点返回 `#extensionsMenuButton`，再次打开菜单后可以重开手机。桌面键盘覆盖 Enter 与空格，移动端覆盖菜单触控、关闭与重开。验证 Shadow DOM 样式隔离、窄屏完整机身与 Home/关闭入口可达。开发监听用 `pnpm watch`。解除直连用 `pnpm st:unlink`。具体命令与发版流程以 README 为准。

独立预览使用隔离的测试数据，避免向用户真实对话写入。独立预览通过后，ST 入口、宿主样式、聊天切换和持久化仍需在专用测试对话中验证。

数据库可用 `/?database=1` 快捷进入，复用 `data-state=empty`、`error`、`unavailable`、`unsupported` 和响应式参数。检查对象搜索、列及引用说明、便捷查询、标准世界日期、JOIN、只读拒绝、200 行截断与超时恢复，以及 Home/关闭后恢复和聊天切换后的草稿、结果、滚动位置。生产插件通过 Memory 正式数据库 capability 查询，不加载 SQLite Worker/WASM。独立预览的 Fake Memory 仅在预览 bundle 使用 SQLite。世界日期使用 `date(world_time)`；直接查 `src_story_state` 的源列时引用 `"current_time"`，避免 SQLite 内置时钟关键字。

验收报告注明实际执行的检查、结果与未验证范围。截图、日志和本地报告放在忽略目录；已跟踪文件不得引用 tmp 中的资源。

## 手机页面约定

2026-10-30 UI 调整验收：Edge 在 1280px、320px、390px 验证摄像头右侧 X、44px 实际点击区域、机身无顶部额外占位、关闭与 Escape 焦点恢复、搜索 Placeholder 与无聚焦描边，以及展开的来源属性列表。Inter 通过 Google Fonts 成功加载，阻断字体请求后页面仍可使用。真实 ST 独立测试数据目录验证资料读取、更新和聊天切换通过；没有修改用户聊天。

`device/` 管理前台页面、App 内存会话与进入、退出转场，主屏常驻；App 首次打开挂载，Home 保留到后台，Expose 明确退出才卸载。关闭原生 dialog 保留手机会话，重开恢复原前台页，刷新 ST 清空内存会话。秒表使用 `performance.now()` 与累计时间计时，后台与关闭期间继续累计，只在前台刷新显示；从 Expose 退出后重进从零开始。

后台验收：物理与软件 Home 的单击均返回主屏，双击均进入后台；双击可中断单击退场。主屏不提供额外后台入口，Expose 不显示主屏/退出按钮、提示、页码或切换箭头。卡片按最近使用排列，以壁纸、中央真实页面预览、两侧邻卡和主屏同款图标显示。左右拖动与方向键选卡，点击卡片/图标或 Enter 打开，保留当前页；上滑 90 逻辑像素或 Delete 播放退场后移除卡片，邻卡补位并获得焦点，全部退出只显示壁纸，单击 Home 返回主屏。检查鼠标/触控的方向锁定和短拖回弹，普通 Tab 不进入屏外卡片；关闭时清除拖动并完成退出，重开保持可用。减少动态效果下直接切换与退出。关闭与重开保留当前页，隐藏 App 和隐藏栈页不能参与 Tab 导航。资料覆盖分类、搜索、滚动、详情返回与后台聊天切换；数据库覆盖对象详情返回、SQL 草稿/结果、背景聊天切换后滚动恢复，隐藏页不得把已有滚动位置写成零。

设置验收：`/?settings=1` 或主屏进入「设置 → 壁纸」，选择 ST 背景、默认渐变和模糊并应用，返回主屏检查只模糊壁纸。HTTP/HTTPS 自定义图片先验证、再应用保存；非法协议、图片加载失败、ST 背景读取失败、重试和应用反馈均可见。验证期间输入和应用锁定。返回放弃未应用修改。独立预览刷新后恢复自己的 localStorage 设置；真实 ST 刷新后核验 `extensionSettings.ste_phone`，同时确认 ST 自身背景没有变化。

`foundation/Page` 提供唯一内容滚动层，顶部预留状态栏与可选导航栏，底部预留可选 footer 与安全区，scroll-padding 与内容内边距同步。导航和 footer 半透明叠在内容上；系统状态栏独立于应用转场。320px、390px、矮屏与放大文字时检查完整机身、首尾内容、关闭入口及 Home 均可达，应用缩放动画的起点需要从实际屏幕坐标换算到逻辑坐标。键盘进入应用后落在返回按钮，退出回对应应用图标；动画期间阻止重复导航并支持减少动态效果。全屏响应式模式与拖拽只在代码中显式启用时生效，默认界面不提供切换控件。
