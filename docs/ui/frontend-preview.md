装饰按region身份与显式seed固定随机序列，在多边形内采样，并拒绝与水面、道路、重要建筑和地标冲突的楼块。候选网格每区域约1000格以内，密度控制保留比例；这是装饰采样预算，不截断模型语义要素。局部几何和相交障碍参与缓存签名，远处无关新增或修改不改变原区域。道路使用世界宽度随缩放投影，街区保留街巷空隙。当前避让处理平面几何，没有桥下多层或立交语义，真实地理尺度和未提供道路仍需用户确认。

## 地图原生工具循环（2026-11-05）

首轮请求仅包含任务指令、选中地点或坐标以及剧情读取许可。地图与剧情内容由助手主动调用工具获得，剧情目录只列已选表。记录每页最多 50 条，仅已返回记录的稳定身份可用于新增资料关联。助手串行修改任务草稿，结构错误返回字段路径，地图检查可反馈地点引用、区域归属、事件关联、道路端点引用，以及本轮修改区域的零面积和道路的零长度。路线查询继续验证既有道路链连通。检查范围不含轮廓自交、穿水、物理道路交点或视觉分析。
