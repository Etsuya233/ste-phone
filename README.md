# STE Phone — SillyTavern 插件发布分支

此分支由源码构建生成，源码与问题反馈：https://github.com/Etsuya233/ste-phone

## 安装与运行要求

当前版本：0.0.10。资料与数据库功能需要 **STE Memory >= 0.2.6**（提供 STE_MEMORY_API.database v1）。请先升级 Memory，再刷新 ST。

在 ST「扩展 → 安装扩展」中填写：

| 插件 | 仓库 URL | Branch or tag name |
| --- | --- | --- |
| STE Memory >= 0.2.6 | https://github.com/Etsuya233/ste-memory | release/sillytavern-plugin |
| STE Phone | https://github.com/Etsuya233/ste-phone | release/sillytavern-plugin |

安装后刷新页面，从聊天输入区的**魔法棒菜单 → 小手机**打开。更新时使用扩展面板的 Update。未连接 Memory 时手机外壳、秒表与组件应用仍可使用。
