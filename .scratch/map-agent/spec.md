# 剧情地图 Agent

状态：实现与验收完成。用户已确认交互与数据方案，并明确要求 Sol 子代理实现。

地图以 Leaflet 平面示意图为主体，底部可折叠助手负责创建、自然语言局部修改和从剧情更新。固定流程为读取地图及选择的剧情资料、生成严格 JSON、地图高亮预览、应用或继续调整或放弃。选中地点与空白地图位置可带入指令。应用后支持一次撤销，撤销同样持久化并推进版本。查询与路线仅临时显示，路线不能创建道路。

地点、区域、道路及事件拥有稳定地图身份；资料地点通过稳定记录身份匹配，别名用于检索，同名歧义不得静默覆盖。未有位置的地点保留待定，事件未知剧情时间保留未知。Memory 通过公开 schema 与 src_* 视图取材，默认选地点、世界状态、纪要及事件表，用户可明确调整其他表；剧情总结独立附加。所有补充内容标注来源，不回写 Memory 或 ST 正文。

数据按聊天与稳定空间隔离。模型失联时保留已存地图浏览，生成要求当前空间可确认。一次任务固定会话归属；Home 与关闭继续，Expose 退出及切聊天取消生成。保存失败保留完整提案，重试不重新生成；已提交原聊天的保存等待确认，切换后重新读取已确认结果。非法 JSON、截断、非法几何与悬空关联整批拒绝。

生产与独立预览共用实现，?map=1 直达，map-test=empty/slow/error/invalid/length/save-error 提供模拟状态。真实模型验收只在 tmp 脚本读取用户指定配置，请求配置端点；三个不同世界场景和局部更名结果通过生产协议校验后绘制。脚本、回复与截图均不进入 Git。
