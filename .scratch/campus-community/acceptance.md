## 浏览器验收

主代理通过 Edge CUA 操作生产共用预览页面，检查 320px 和 390px 窄屏。主要结果如下：

| 场景 | 结果 |
| --- | --- |
| 指定当前主号和同人物小号生成互动 | 保存 20 条实际评论，仅指定账号发言；当前账号可以参与 |
| 取消点赞、手动回复 | 取消点赞只减一份；回复进入目标讨论串，实际评论数增加一 |
| 删除已有回复的原评论 | 总数减一，已有回复保留并注明原评论已删除 |
| 创建与切换小号 | 公开主页只展示账号资料；手动发帖采用当前小号署名 |
| 图文草稿与手动生图 | 手动调用模拟 Image Hub 后关联图片，确认发布才写入帖子 |
| 刷新与关注 | 已保存账号、帖子、图片和热度保持，关注页按当前账号关注关系筛选 |
| 背景计数与续聊 | 背景评论 1,500 加实际 1 条显示 1,501；新增 5 条后显示 1,506，未加载提示仍为 1,500 |
| 批量发帖保存失败 | 显示重试或舍弃，关闭重开保留；重试保存原三条帖子和新路人，没有重复内容 |
| 慢生成停止 | 恢复编辑，原信息流保持，不留下半批帖子 |
| 空社区 | 展示账号引导，可自动生成首批路人及帖子，明确提示保存成功 |
| 保存失败时从 Expose 退出 | 返回待保存页，用户可重试或舍弃，结果不会因退出而静默丢失 |

截图保存在忽略目录 `tmp/campus-acceptance/phone-320.png`、`discussion-390.png`、`save-error.png` 和 `quit-guard.png`。浏览器临时视口覆盖已清除。

验收发现并修复：社区样式未进入统一 `style.css`；成功生成缺少结果反馈；预览旧桌面布局缺少社区入口，导致 Home/Expose 返回时报应用未安装。成功状态最终按提交批次 ID 确认，不通过比较历史列表推测。修复后已复验相关流程。
