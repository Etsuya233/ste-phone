## 浏览器验收

主代理通过 Edge CUA 操作生产共用预览页面，检查 320px 和 390px 窄屏。主要结果如下：

| 场景 | 结果 |
| --- | --- |
| 指定当前主号和同人物小号生成互动 | 保存 20 条实际评论，仅指定账号发言；当前账号可以参与 |
| 取消点赞、手动回复 | 取消点赞只减一份；回复进入目标讨论串，实际评论数增加一 |
| 删除已有回复的原评论 | 总数减一，已有回复保留并注明原评论已删除 |
| 创建与切换小号 | 公开主页只展示账号资料；手动发帖采用当前小号署名 |
| 图文草稿与手动生图 | 手动调用模拟 Image Hub 后关联图片，确认发布才写入帖子 |
| 刷新与关注 | 已保存账号、帖子、图片和热度保持，关注页按当前账号关注关系筛选 |
| 背景计数与续聊 | 背景评论 1,500 加实际 1 条显示 1,501；新增 5 条后显示 1,506，未加载提示仍为 1,500 |
| 批量发帖保存失败 | 显示重试或舍弃，关闭重开保留；重试保存原三条帖子和新路人，没有重复内容 |
| 慢生成停止 | 恢复编辑，原信息流保持，不留下半批帖子 |
| 空社区 | 展示账号引导，可自动生成首批路人及帖子，明确提示保存成功 |
| 保存失败时从 Expose 退出 | 返回待保存页，用户可重试或舍弃，结果不会因退出而静默丢失 |

## Twitter 信息流与交互优化（2026-11-11）

首页改为常驻当前账号身份条，新增独立「切换账号」页；生成中切换会打开停止确认，保存阶段禁用切换。关注页为空时显示推荐关注，排除当前人物的大小号和没有帖子的账号。信息流卡片改为头像左置，单图使用大图，双图两列，更多图三列；点赞使用心形图标和品牌粉色，计数使用紧凑格式。

帖子详情把「调整背景热度」和「删除帖子」收进 `···` 菜单，「生成评论」留在评论标题旁。评论显示本地发送时间和回复目标，楼内回复恢复为头像左置的正常宽度。手动评论保存后滚动并标出新评论；图片查看支持上一张、下一张和方向键。

发布页使用三列配图网格和单图编辑器，支持描述、Prompt、图库、生成和上移/下移；缺少描述时对应缩略图显示红点和具体提示。发布、取消和编辑账号资料时检查未保存内容并确认舍弃。手动发布、手动评论和 AI 批次共用一次性保存定位，信息流和详情页滚动到新内容并短暂高亮；同批内容只定位一次，切换标签不会重复滚动；提示在导航栏下方固定显示，可手动关闭。AI 批次保存完成后自动回到原页面。批量创建页支持按姓名搜索并保留已有账号标记；账号编辑页可从图库选择或清除头像。

评论新增可选 `createdAt`，旧数据可继续读取。`CampusSavedBatch` 只在内存中保存批次与新内容 ID，不写入聊天元数据。

Edge 独立预览在 390px 与 320px 宽度验证首页、账号主页、切换账号、帖子详情、操作菜单、发布网格、未保存确认、AI 发帖后定位、AI 评论楼内定位、手动发布与点赞、关注页推荐、手动评论、账号资料舍弃确认、批量创建搜索、头像图库选择和图片查看舍弃确认，控制台无错误。`pnpm test` 342 项、`pnpm typecheck`、`pnpm lint`、变更目录 Prettier 与 `pnpm build` 通过。本轮未在真实 ST 宿主内执行界面回归。
